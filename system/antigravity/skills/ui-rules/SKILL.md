# Правила интерфейса

1. Прочитать через `view_file` по порядку: `~/.gemini/config/skills/ui-rules/rules/00-общее.md`, затем файл семейства рядом: `веб.md`, `боты.md` или `программы.md`, затем `UI-RULES.md` в корне проекта, если есть. Подписи, даты, ошибки: `~/.gemini/config/skills/ui-rules/rules/словарь.md`.
2. Значения только из таблиц. Нет значения: спросить владельца, не придумывать.
3. В ТЗ агентам agy и субагентам вставлять `~/.gemini/config/skills/ui-rules/rules/промпт-блок.md` дословно.
4. У проекта нет `UI-RULES.md`: создать по `~/.gemini/config/skills/ui-rules/rules/шаблон-проекта.md`.
5. После правок: `node "$HOME\.gemini\config\skills\ui-rules\scanner\ui-check.mjs" <папка проекта> --diff` (на других системах: `node "~/.gemini/config/skills/ui-rules/scanner/ui-check.mjs" <папка проекта> --diff`), итог одной строкой владельцу.
6. Космоскай живёт по своей библиотеке, эти правила его не касаются.

Оригинал правил и сканера лежит в <VIBECODING>/_Проекты/ui-rules, копия в скилле нужна для переноса на другие машины; при расхождении главный оригинал.
