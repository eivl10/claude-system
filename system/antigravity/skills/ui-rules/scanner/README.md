# Проверялка правил интерфейса

Маленькая программа. Проходит по папке проекта и показывает места, где код нарушает правила из `rules/`. Ничего не исправляет и не меняет, не ходит в сеть, не тратит ИИ.

## Как запустить

Нужен Node 18 или новее. Команда для PowerShell:

```powershell
node "<VIBECODING>\_Проекты\ui-rules\scanner\ui-check.mjs" "F:\путь\к\проекту"
```

Дополнительно:

- `--diff` проверяет только строки, добавленные после последнего коммита, и новые файлы. Нужен git. Без git программа скажет об этом и проверит всё.
- `--strict` возвращает код выхода 1, если что-то найдено. Без него код всегда 0.
- `--tokens "файл"` указывает файл значений. Можно несколько раз.

## Файл значений

Это файл, где цвета и размеры записаны один раз, например `tokens.css`. В нём сырые числа и цвета разрешены. Где он, программа узнаёт так:

1. из `--tokens`;
2. из строки `Файл значений: путь` в `UI-RULES.md` проекта;
3. если нет ни того ни другого, файлом значений считается блок `:root { ... }`.

## Что значат коды

| Код | Что нашлось |
|---|---|
| color | цвет записан прямо в коде, а не взят из файла значений |
| px | размер в px записан прямо в коде. 0 и 1px можно |
| blur | размытие или backdrop-filter |
| shadow | тень, кроме none |
| gradient | градиент |
| red | красный оттенок, где угодно, и в файле значений тоже |
| emoji | цветной значок в коде бота, например ❌ и ✅. Чёрный ✖ без цвета можно |
| inter | шрифт Inter |

Вывод: файл, номер строки, код, кусок строки. Внизу сводка по кодам и время.

## Чего программа не ловит

- Неверную роль: кнопка может быть оформлена верными значениями, но не тем видом, который нужен.
- Тексты: названия действий, даты, формулировки ошибок.
- Вёрстку и порядок элементов, размеры, заданные не в px, например в rem и em.
- Цвета, написанные словами, например red, и цвета в картинках.
- Красный, спрятанный в переменной без значения рядом.
- Сырые значения в комментариях: комментарии CSS и HTML пропускаются.
- Срабатывает и на ссылки-якоря вида `#abc`, если они не в href. Это редкая ложная тревога.

## Проверка самой программы

```powershell
node "<VIBECODING>\_Проекты\ui-rules\scanner\selftest.mjs"
```

Программа проходит по папке `test-fixture` с намеренными нарушениями. Код выхода 0 значит, что каждый код находится.
