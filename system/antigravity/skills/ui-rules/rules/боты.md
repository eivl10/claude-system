# Правила Telegram-ботов

Значения предварительные, правятся по ходу разработки. Источник: четыре работающих бота владельца: Блябот, ccbot, Говорутка, бот-продавец. Каждое значение сверено с кодом на диске, кроме помеченных «не сверено». Админка бота-продавца эталоном не служит.

## 1. Главное меню

| Роль | Правило | Источник |
|---|---|---|
| Постоянная клавиатура под полем ввода | Не использовать. Ни в одном из четырёх ботов её нет | все четыре |
| Меню | Один экран-сообщение с inline-кнопками. Открывается командой /start или /settings | Блябот, admin.py:185-207, main.py:145 |
| Переход между экранами | Правится то же сообщение, новое не отправляется. Сбой «сообщение не изменилось» гасится молча | Блябот, main.py:141-143 |
| Боту без разделов | Меню не нужно: список команд в BotCommand и /help | бот-продавец, admin.py:30-49; ccbot, bot.py:1948-1956 |

Когда нужно меню, а когда достаточно команд: меню для настроек и выбора из списка, команды для разовых действий администратора.

## 2. Inline-кнопки

| Роль | Значение | Источник |
|---|---|---|
| В ряду | 2 кнопки для меню и выбора из списка | Блябот admin.py:199-204; ccbot directory_browser.py:102-112; Говорутка handlers.py:55, 130 |
| В ряду одна | Длинные подписи, список сущностей с названиями, одиночное действие, «Назад» | Блябот admin.py:200, 215, 228 |
| В ряду три | Только листание и пульт навигации. Не для действий | ccbot directory_browser.py:167-188, interactive_ui.py:133-146 |
| Длина подписи | До 13 символов из данных при 2 в ряду, до 40 при одной в ряду. Лишнее обрезается, ставится «…» | ccbot directory_browser.py:157; Блябот admin.py:215 |
| Эмодзи | Один функциональный эмодзи первым в подписи кнопки действия или перехода. У «Назад», «Отмена» и кнопки подтверждения эмодзи нет | Блябот admin.py:199-215, 298; ccbot directory_browser.py:106-117 |
| Состояние кнопки | В самой подписи: «Реплай: Включено» и «Реплай: Выключено», знак «▶ » у выбранного | Блябот admin.py:203, 212 |

Эмодзи в кнопке единственная иконка, которую позволяет Telegram, поэтому каталог штампов C9 здесь не запрещает его. Причину записать в README бота. В тексте сообщений эмодзи не ставить.

## 3. Назад и отмена

- «« Назад» всегда одна кнопка отдельным последним рядом экрана. Источник: Блябот, admin.py:181-182, 216, 230, 247, 263, 278.
- На экране с листанием листание идёт отдельным рядом выше, «« Назад» остаётся последним. Расхождение: Говорутка ставит 🔙 в середину ряда листания, ccbot пишет «Cancel». Выбрано как в Блябот: одно место на всех экранах.
- Отмена ввода текста: команда /cancel. Каждый запрос ввода заканчивается строкой «/cancel — отмена», ответ бота: «Отменено.». Источник: Блябот, admin.py:147, main.py:153-156.

## 4. Подтверждение опасного действия

Опасное: удаление, сброс настроек, всё, что нельзя вернуть. Экран подтверждения:

```
<b>Удалить триггер t1?</b>
Это нельзя отменить.

[Удалить] [Отмена]
```

- Заголовок жирный, вопрос с названием объекта. Вторая строка всегда «Это нельзя отменить.».
- Две кнопки в одном ряду, без эмодзи: действие глаголом из `словарь.md`, как «Удалить», слева и «Отмена» справа. «Отмена» возвращает на предыдущий экран.
- Безопасные действия подтверждения не просят. Источник: Блябот, admin.py:297-298, main.py:199-209.

Отличие ccbot: запрос прав вынесен в верхний ряд кнопок над навигацией. Годится только для вопросов, которые задаёт внешняя система, и записывается в отличия проекта. Подписи кнопок всё равно по словарю.

## 5. Длинные списки и листание

| Случай | Формат |
|---|---|
| Выбор из списка кнопок | Страницами по 6 кнопок. Ряд листания: ◀, счётчик «1/3», ▶. Крайняя стрелка на первой и последней странице скрыта. Счётчик нажимается вхолостую. Источник: ccbot, directory_browser.py:148-180 |
| Справочник одинаковых коротких кнопок | До 30 на страницу, 2 в ряду. Источник: Говорутка, handlers.py:54-55. Стрелки ⬅️ и ➡️ из Говорутки не берутся, листание как в строке выше |
| Список в тексте сообщения | Нумерованный, каждый элемент в <code>. Лимит 3300 символов, остаток заменяется строкой «… и ещё N». Источник: Блябот, admin.py:31, 167-178 |

Нумерация нужна, чтобы удалять по номеру.

## 6. Сортировка списков

- Справочники, где пользователь ищет по названию: алфавит. Источник: ccbot, directory_browser.py:137-144; Говорутка, langs.py.
- Всё, что со временем появляется: свежее сверху. Источник: ccbot, сессии; в facts записано без номера строки, не сверено.
- Списки, которые пользователь наполняет сам: порядок добавления, чтобы номера не прыгали. Источник: Блябот.

## 7. Формат сообщения

- Разметка HTML. Заголовок первой строкой в <b>. Дальше пустая строка и тело. Значения, идентификаторы и фразы в <code>. Источник: Блябот, admin.py:253-258, 281.
- Всё из данных пропускается через html.escape.
- Исключение: текст, который пишет человек или ответ модели. Там разметка отключена, иначе чужие символы сломают сообщение. Источник: бот-продавец, tg.py:2294 в facts, не сверено.
- Числа с единицей через пробел: «Пауза: 30 секунд». Даты, числа и деньги по `словарь.md`: «14 декабря», с годом «14.12.2027».
- Эмодзи в тексте сообщений нет, только в кнопках. Исключение владельца: тон бота, например Говорутка, записывается в отличия проекта.

## 8. Ожидание

- Перед долгой работой бот шлёт действие чата: набор текста, для голоса запись голоса. Источник: Говорутка, handlers.py:179, 201 в facts, не сверено; ccbot, bot.py:566 в facts, не сверено.
- На любое нажатие inline-кнопки бот отвечает пустым подтверждением, чтобы пропали «часики». Источник: Блябот, main.py:212.
- После сохранения значения: «Готово.» и обновлённый экран. Источник: main.py:237-239.
- Знак успеха, если нужен: чёрная галочка «✓» U+2713. Цветные эмодзи-значки не использовать. Зелёная галочка-эмодзи в ccbot и Говорутке так сейчас в коде, не повторять.

## 9. Ошибки

- Форма: «Не вышло: причина.» Источник: Блябот, main.py:211.
- Неверный ввод: «Не принято: что не так.» и вторая строка «Нужно повторить ввод или /cancel.». Источник: main.py:233.
- Причина называет формат, который ждали: «нужно число», «нужно две строки: 1) …, 2) …». Источник: admin.py:98, 122.
- Красный крест-эмодзи не использовать, так сейчас в коде ccbot и Говорутки, не повторять. Если нужен знак, только чёрный крест «✖» без эмодзи-селектора (U+2716, без U+FE0F), чтобы Telegram не рисовал красный значок. Решение владельца 03.11.

## 10. Пустые состояния

- Одно предложение с точкой, и что сделать дальше, если есть выход. Примеры: «Активных товаров нет.» «Групп пока нет: бот увидит группу, когда там кто-то напишет.» Источник: бот-продавец, admin.py:66 в facts, не сверено; Блябот, admin.py:219.
- Пустой список внутри экрана: «<i>пусто</i>». Источник: Блябот, admin.py:169.

## 11. Команды

| Команда | Что делает |
|---|---|
| /start | Открывает главный экран. Сбрасывает ожидание ввода. Источник: Блябот, main.py:145-151 |
| /help | Список команд: «команда — что делает», по строке на команду. Источник: бот-продавец, admin.py:30-49 |
| /cancel | Выход из ожидания ввода, ответ «Отменено.» |

Все команды регистрируются списком с короткими описаниями. Источник: ccbot, bot.py:1948-1956.

## Примеры текстов

- «Настройки бота», строка «Триггеров: 3», строка «Пауза: 30 секунд».
- «Удалить триггер t1?» и «Это нельзя отменить.»
- «Не вышло: нет такого триггера.»
- «Нужны номера, например 2 5, или сами элементы, по одному на строку.» и ниже «/cancel — отмена».
