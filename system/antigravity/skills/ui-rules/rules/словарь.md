# Словарь интерфейса

Общий для веба, ботов и программ. Одно действие, одно название. Первая буква заглавная, остальные строчные, точки в конце нет. Подпись в таблице: слово без эмодзи и значков. Значки по семейству решает его файл.
Источники вариантов: кабинет 8, админка бота-продавца, боты, AGY Switch, SMC-pad. Совпало во всех: «Сохранить», «Отмена». Остальное выбрано из встреченных слов, предварительно.

## 1. Действия

| Действие | Название | Не использовать | Заметка |
|---|---|---|---|
| Записать изменения | Сохранить | Применить, OK, Записать | Подтверждено владельцем 15.11.2026: «Применить» нигде не использовать |
| Отметить вещь выданной покупателю | Забрал | Продано, Забрал всё | Владелец, 15.11.2026: одно слово на это действие вместо «Продано» и «Забрал всё» |
| Отказаться от действия или закрыть форму без записи | Отмена | Отменить, Нет, Cancel | Так подписана вторая кнопка диалога |
| Убрать насовсем | Удалить | Стереть, Убрать, Del | Только с подтверждением, раздел 5 |
| Править существующее | Изменить | Редактировать, Правка | |
| Новая запись из готовых данных | Добавить | Плюс, New | Подпись вида «Добавить аккаунт»: глагол и предмет |
| Новая запись с нуля | Создать | Новый, Make | |
| Вернуться на шаг | Назад | Вернуться, Back | |
| Убрать окно, панель, сообщение | Закрыть | Скрыть, Крестик словом | |
| Открыть объект | Открыть | Перейти, Показать | |
| Искать | Найти | Поиск на кнопке, Искать | Подпись поля: «Поиск» |
| Загрузить заново | Обновить | Перезагрузить, Refresh | |
| Очистить поля или список | Очистить | Стереть, Сбросить | «Сбросить» только для возврата к исходным значениям |
| Вернуть исходные значения | Сбросить | Откатить, Reset | |
| Подтвердить прочитанное | Понятно | OK, Ладно | Только в окне, где выбора нет |
| Выйти из аккаунта или программы | Выйти | Выход, Logout | |
| Отправить | Отправить | Послать, Submit | |
| Выбрать файл | Обзор | Выбрать файл | Подпись «Выбрать» для выбора из списка |
| Включить и выключить | Подпись параметра, без глагола | Включить, Отключить на самом переключателе | Состояние: «Включено» и «Выключено» |

Слова вне таблицы: сначала добавить строку сюда, потом использовать.

## 2. Даты и время

| Что | Формат | Пример |
|---|---|---|
| Дата | число и месяц словом | 14 декабря |
| Дата, когда год важен | ДД.ММ.ГГГГ | 14.12.2027 |
| Время | ЧЧ:ММ, 24 часа | 14:30 |
| Дата и время | дата, пробел, время | 14 декабря, 14:30 |
| Недавнее | «только что», «5 минут назад», дальше дата | |

## 3. Числа и деньги

| Что | Формат | Пример |
|---|---|---|
| Тысячи | пробел между разрядами | 12 500 |
| Деньги | сумма, пробел, знак валюты, копейки только если не нули | 12 500 ₽ |
| Проценты | число, пробел, знак | 15 % |
| Число с единицей | число, пробел, единица | 30 секунд |
| В таблицах | числа и деньги выровнены вправо | |

Пробелы в числах и перед знаками неразрывные.

## 4. Пустые состояния

Три части: что пусто, почему или что это значит, что делать. Если действия нет, третья часть пропускается. Без эмодзи и шуток.

| Случай | Образец |
|---|---|
| Данных ещё нет | «Заказов пока нет. Они появятся после первой покупки.» |
| Поиск без результата | «Ничего не найдено по запросу «кофе». Можно изменить запрос или сбросить фильтры.» |
| Нет доступа | «Нет доступа к разделу. Доступ выдаёт администратор.» |

## 5. Ошибки

Структура: что случилось, потом что делать. Текст безличный, без обращения. Без вины пользователя, без технического текста, без восклицательных знаков. Подробности сбоя в журнале, не на экране.

| Случай | Образец |
|---|---|
| Неверный ввод | «Номер телефона неполный. Нужно 10 цифр.» |
| Сбой сохранения | «Не удалось сохранить. Нужна связь с сервером, затем повторить.» |
| Нет связи | «Нет связи с сервером. Повторить можно через минуту.» |
| Нет прав | «Это действие недоступно. Права выдаёт администратор.» |

Значок ошибки и цвет: в файле семейства. В вебе красный не использовать: перед текстом ошибки чёрный «✖», цвет основного текста. В ботах красный ❌ не использовать, только чёрный крест «✖» без эмодзи-селектора (владелец, 03.11).

## 6. Подтверждение удаления

- Любое необратимое действие требует подтверждения.
- Заголовок называет, что будет удалено: «Удалить заказ 1042?»
- Под заголовком одна строка о последствии: «Это нельзя отменить.»
- Две кнопки: действие глаголом, как в разделе 1, и «Отмена». «Да» и «Нет» не использовать нигде, в ботах тоже.
- Кнопка отмены стоит рядом и безопасна по умолчанию: Enter её не нажимает.
- Обратимое действие подтверждения не требует.
