# Правила интерфейса: набор файлов, чтобы агенты делали кнопки, поля, подписи и таблицы одинаково

Это короткие файлы с правилами. Агент читает их вместе с твоим заданием и не придумывает свои размеры, цвета и слова. Всё предварительное: значения подтверждаются после просмотра страницы-образца глазами, остальное дополняется в процессе работы.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| [00-общее.md](00-общее.md) | Семь коротких правил для всех. Без чисел |
| [словарь.md](словарь.md) | Как называть действия, как писать даты, деньги, ошибки и пустые экраны |
| [веб.md](веб.md) | Таблица значений для сайтов: админка с меню слева, сайт с точками справа |
| [боты.md](боты.md) | Правила Telegram-ботов |
| [программы.md](программы.md) | Правила программ для компьютера |
| [промпт-блок.md](промпт-блок.md) | Текст, который вставляется агенту в задание |
| [шаблон-проекта.md](шаблон-проекта.md) | Заготовка файла правил для одного проекта |

Правила веба, ботов и программ не смешиваются.

## Как пользоваться

1. Начинаешь проект: скопируй `шаблон-проекта.md` в корень проекта под именем `UI-RULES.md`, укажи семейство. Проси агента заполнить, вручную не надо.
2. Ставишь задачу агенту: вставь в неё содержимое блока из `промпт-блок.md`. Он сам найдёт нужные файлы.
3. Хочешь поменять размер, цвет или слово: открой таблицу в файле семейства, поправь одну строку. Скажи агенту «синхронизируй код с таблицей».
4. Агент не нашёл значения в таблице: он должен спросить. Ответ вноси в таблицу, а не в код.

В проекте записываются только отличия от семейства, каждое с причиной.

## Что предварительное

- Числа в `веб.md`, `боты.md`, `программы.md`: до просмотра образца глазами.
- Словарь: слова выбраны из встреченных в пяти проектах, нужных слов может не хватить.
- Тёмная тема, мобильный вид админки и прочее лежит в разделах «Позже» файлов семейств.

## Проверялка

Проверялка есть: небольшая программа проходит по проекту без ИИ и показывает сырые цвета и размеры, размытие, тени, градиенты, красный, шрифт Inter и цветные значки в ботах. Ничего не меняет.
Запуск и что она не ловит: [../scanner/README.md](../scanner/README.md).
