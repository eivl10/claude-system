# Get Shit Done (GSD) Workflow

## Цель
Максимизировать продуктивность через чёткое определение задач, приоритизацию и фокусированное выполнение.

## Принципы GSD

### 1. Определение задачи (Define)
- Чётко сформулируй **что** нужно сделать.
- Определи **критерии завершения** (Definition of Done).
- Выяви зависимости и ограничения.

### 2. Разбиение (Break Down)
- Разбей большую задачу на подзадачи (атомарные и проверяемые).
- Используй артефакт `task.md` для трекинга прогресса.

### 3. Приоритизация (Prioritize)
- Фокус на важных и срочных задачах.
- Делегируй или автоматизируй рутину.

### 4. Выполнение (Execute)
- Фокус на **одной задаче** за раз.
- Никаких контекстных переключений без необходимости.
- Промежуточные чекпоинты после каждой подзадачи.

### 5. Завершение (Complete)
- Проверь критерии завершения.
- Зафиксируй результат.
- Отметь задачу как completed в `task.md`.
- Извлеки уроки (self-anneal) и обнови инструкции, если необходимо.

## Метрики успеха
- Все подзадачи имеют чёткие критерии завершения.
- Прогресс виден в `task.md` в реальном времени.
- Задачи завершаются полностью.
- Уроки фиксируются для будущих итераций.
