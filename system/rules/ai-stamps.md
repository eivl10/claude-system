# ИИ-штампы: не выдавать шаблонный вид

Касается любого сайта, лендинга, макета, интерфейса и текстов к ним, моих и агентских.

1. Перед выдачей и перед постановкой задачи агенту сверить с <HOME>\.claude\design-library\ai-stamps.md (jDocMunch: local/design-library, search_sections).
2. Штамп по умолчанию не брать. Можно, если есть причина из задачи (функция, прямая просьба владельца) и она записана в README проекта. Запрет не заменяет решение: форма берётся из содержания проекта, не из другого шаблона.
3. Слова владельца «ИИшно / шаблонно / как у всех / слишком X»: в тот же ход дописать запись в каталог (источник, дата, проект, цитата) и сказать об этом одной строкой.
4. В промпты agy и субагентам вставлять секцию «Промпт-блок» из каталога дословно: они это правило не видят.
5. После UI или текста сайта один проход jev_review по промпт-блоку. Браузер и скриншоты не нужны.

Приоритет: прямая просьба владельца выше каталога. Режим «продающий лендинг» (библиотека Космоскай) не затрагивается, пока владелец не скажет иначе.
