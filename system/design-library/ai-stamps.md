# Каталог ИИ-штампов

Что читается как «сделано нейросетью по шаблону». Глобально, для любого сайта, лендинга, макета, интерфейса и текстов к ним. Правило применения: `~/.claude/rules/ai-stamps.md`.

## Правила пополнения

- Запись: `id | штамп | почему читается как ИИ | как заметить | что вместо | источник | применимость | дата`.
- Источник, статус растёт в этом порядке: **интернет** (названо в нескольких живых статьях, список внизу) → **замечено** (поймал в своём или агентском выводе) → **владелец** (его слова, жёстко). Выдумки agy без подтверждения в каталог не попадают.
- Слова владельца «ИИшно / шаблонно / как у всех / слишком X»: запись в тот же ход, с цитатой, датой и проектом. Одна строка владельцу о том, что записано.
- Поймал сам: запись плюс строка владельцу.
- Дубли склеивать, не плодить. Освежать исследование агентом только по слову владельца.
- Применимость: `все` / `портфолио, кейсы` / `не Космоскай` (там приём осознанный, см. `landing-patterns.md`).
- Оговорка: источники из интернета это блоги и гайды, не исследования с пользователями. Они описывают недоверие («никто не принял решения»), а не измеренное раздражение.

## Как применять

- Штамп по умолчанию не брать.
- Можно, если есть причина из задачи (функция или прямая просьба владельца). Причина записывается в README проекта.
- Запрет не заменяет решение: форма берётся из содержания проекта, а не из другого шаблона. Заменить один штамп другим нельзя.
- Прямая просьба владельца выше каталога.

## Убрано как неподтверждённое (принесено agy, в интернет-источниках не найдено)

Hairline-сетка, зернистость и шум, клон Linear, мок-дашборды, 3D-руки и «кибер-мозги», marquee с fade, градиентные рамки, sticky-навбар-пилюля, фоновые кляксы и частицы (как штамп), hover-отскок. Bento: упомянут один раз мельком, как штамп не ведём. Вернуть можно только после подтверждения живым источником или словом владельца.
