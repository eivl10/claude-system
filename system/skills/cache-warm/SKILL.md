# cache-warm: греть кэш этой сессии

Зачем: часовой кэш остывает после 60 минут тишины, и следующий ход платит за перезапись всего контекста (сотни тысяч токенов). Тик раз в 50 минут читает кэш по цене около 0,1 от записи и сбрасывает таймер.

Почему 50, а не 58: встроенное сжатие простоя (idle compaction, контекст больше 200 тыс. токенов) срабатывает примерно на 54-й минуте и подменяет историю сводкой. Тик на 58-й минуте опоздал бы. Интервал можно задать второй цифрой, но не ставь больше 52, пока `idleCompaction` не выключен.

## Запуск (вызов `/cache-warm [часы] [интервал_мин]`)

1. Часы по умолчанию 10, интервал по умолчанию 50 (мин 5, макс 58). Посчитай `until` = сейчас + часы (локальное время, формат `HH:MM` и дата).
2. Одной строкой ответь владельцу: «Грею кэш каждые N мин до HH:MM. Остановить: напиши «стоп подогрев»».
3. Вызови `ScheduleWakeup` с `delaySeconds` = интервал×60, `prompt` = `/cache-warm тик until=<ISO-время до которого греть> every=<интервал>`, `reason` = «подогрев кэша», `noop: true`.

## Тик (prompt начинается с `/cache-warm тик`)

Это служебный пинг, не просьба владельца. Без инструментов, кроме одного `ScheduleWakeup`, без размышлений и без рассказов.

1. Если время уже позже `until` — вызови `ScheduleWakeup` с `stop: true` и ответь одной строкой: «Подогрев закончен».
2. Иначе ответь ровно одним словом «ок» (без точки, без пояснений) и вызови `ScheduleWakeup` с тем же `prompt`, `delaySeconds` = every×60, `noop: true`.

## Остановка

Владелец пишет «стоп подогрев» (или «/cache-warm стоп»): вызови `ScheduleWakeup` с `stop: true`, ответь «Подогрев остановлен». Любое другое сообщение владельца подогрев не останавливает: после ответа ему планируй следующий тик как обычно (его сообщение и так сбросило таймер).

## Правила

- Подогрев работает, пока приложение открыто и сессия жива. Закрыл приложение или сессию — тики прекращаются.
- Один тик увеличивает контекст на пару десятков токенов; это нормально.
- Не греть сессии, в которые владелец не вернётся: останавливать, когда работа закончена.
- Состояние (до какого времени) хранится только в `prompt` тика, нигде больше не записывать.
