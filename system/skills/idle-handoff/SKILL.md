# idle-handoff: handoff до остывания кэша

Владелец молчит около 50 минут, часовой кэш скоро остынет. Задача: проверить, есть ли актуальный handoff, и если нет, сделать его сейчас.

## Шаги

1. Найди handoff проекта: `HANDOFF.md` в рабочей папке (или файл по соглашению проекта, например HANDOVER_ROUND<N>; брать самый новый).
2. Актуален, если файл есть и после его последнего изменения ты не правил файлы проекта и не принимал новых решений. Время правок сверь по ходу сессии, при сомнении по дате файлов проекта (PowerShell `Get-Item` по изменённым файлам).
3. Актуален: ответь одним словом «ок». Больше ничего.
4. Нет файла или устарел: сразу вызови скилл `handoff` и следуй ему. Никаких дополнительных фраз от себя, сообщение даёт сам скилл.
5. Таймер заново не ставь: новый ScheduleWakeup допускается только после следующего сообщения владельца, и его поставит хук.

## Правила

- Не задавай вопросов владельцу: он не у экрана.
- Если сессия по сути не про работу над проектом (нет проекта, не было правок и решений): ответь «ок», handoff не создавай.
