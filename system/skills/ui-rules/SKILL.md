# Правила интерфейса

1. Прочитать по порядку: `<VIBECODING>\_Проекты\ui-rules\rules\00-общее.md`, затем файл семейства рядом: `веб.md`, `боты.md` или `программы.md`, затем `UI-RULES.md` в корне проекта, если есть. Подписи, даты, ошибки: `rules\словарь.md`.
2. Значения только из таблиц. Нет значения: спросить владельца, не придумывать.
3. В ТЗ агентам agy и субагентам вставлять `rules\промпт-блок.md` дословно.
4. У проекта нет `UI-RULES.md`: создать по `rules\шаблон-проекта.md`.
5. После правок: `node "<VIBECODING>\_Проекты\ui-rules\scanner\ui-check.mjs" <папка проекта> --diff`, итог одной строкой владельцу.
6. Космоскай живёт по своей библиотеке, эти правила его не касаются.
