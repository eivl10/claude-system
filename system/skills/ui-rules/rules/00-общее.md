# Общее для всех семейств
1. Значения только из таблицы семейства. Своих не придумывать.
2. Нет значения в таблице: спросить.
3. Одно действие, одно название из `словарь.md`.
4. Одинаковое выглядит одинаково на всех экранах проекта.
5. Новый вид элемента: сначала в таблицу, потом в код.
6. Проект хранит только отличия от семейства.
7. Правила семейств не смешиваются.
