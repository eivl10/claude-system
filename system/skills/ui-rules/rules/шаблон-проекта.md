# Шаблон: UI-RULES.md в корне проекта

Скопировать в корень проекта как `UI-RULES.md`, заполнить, лишнее убрать. Хранить только отличия от семейства: то, что совпадает, не переписывать.
Правило: сначала запись здесь, потом код. Агент читает этот файл вместе с `00-общее.md` и файлом семейства.

## 2. Где в коде таблица значений

| Что | Где |
|---|---|
| Файл таблицы «роль → значение» | путь в проекте |
| Как значения попадают в код | один абзац: переменные, тема, константы и так далее |
| Кто правит значения | владелец, в таблице; код обновляется следом |

Для проверялки одной строкой, без таблицы:

Файл значений: <путь от корня проекта>

Проверялка `scanner/ui-check.mjs` читает эту строку и не считает сырые числа и цвета в этом файле нарушением. Строки нет: файлом значений считается блок `:root { ... }`.
