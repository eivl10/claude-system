# Landing Page Builder

Обобщение из реального ТЗ (Космоскай, "Интенсив по ритму с Алексом Ксено", `ТЗ_для_ИИ_агентов.md`). Не копипаст того лендинга — свод "из каких блоков и паттернов обычно собирается такая страница", чтобы не пересобирать ТЗ с нуля каждый раз. Конкретные визуальные паттерны (bento grid, glassmorphism, blobs...) — в базе `design-library` (jDocMunch, repo_group design-taste), здесь только структура и техника.

## Перед стартом — спроси

1. Бренд-палитра / логотип / фото — если не переданы, не выдумывать цвета, спросить или запросить брендбук.
2. Какие опциональные секции нужны (галерея/соц.доказательство, FAQ — см. ниже).
3. Референс-стиль по умолчанию — Google One landing page (светлая, воздушная, мягкие градиенты, крупные скругления). Если у пользователя другой референс — заменить, не навязывать этот.

## JS-паттерны (6 штук, все — чистый JS, без библиотек)

**1. Smooth scroll** — якорные ссылки, плавный скролл с учётом offset под sticky header.

**2. Sticky header** — при `scrollY > 80` добавить класс `.header-scrolled`:
```css
background: rgba(255,255,255,0.85);
backdrop-filter: blur(20px);
box-shadow: 0 1px 10px rgba(0,0,0,0.06);
```

**3. Аккордеон** (программа/FAQ) — клик по заголовку → toggle класса `.active`, закрытие остальных элементов в группе, анимация `max-height` + `opacity`.

**4. Scroll-triggered анимации** — `IntersectionObserver` с `threshold: 0.15`. Классы `.animate-fade-up`, `.animate-fade-in`, `.animate-slide-left`, `.animate-slide-right`. База: `opacity: 0; transform: translateY(30px)`. При появлении: `opacity: 1; transform: translateY(0)`. `transition: 0.6s cubic-bezier(0.16, 1, 0.3, 1)`.

**5. Мобильное меню (бургер)** — три полоски → крестик (CSS-transition), полноэкранный оверлей с навигацией, закрытие по клику на ссылку или оверлей.

**6. Горизонтальный скролл галереи** (если есть секция 6) — `scroll-snap-type: x mandatory`, `scroll-snap-align: start` на каждой карточке, опционально стрелки навигации на десктопе.

## Технические ограничения (жёсткие правила)

1. **Один HTML-файл** — весь CSS инлайн в `<style>`, весь JS инлайн в `<script>`. Никаких внешних CSS/JS файлов, кроме Google Fonts CDN.
2. **Никаких фреймворков и сборщиков** — чистый HTML + CSS + Vanilla JS.
3. **Никаких npm/node_modules/build-процесса.**
4. **Изображения** — относительные пути к папке с ассетами. Все пути к картинкам вынести в переменные в начале `<script>`, чтобы легко менять.
5. **Адаптивность** — mobile-first, breakpoints: 768px, 1024px, 1200px.
6. **Accessibility** — `alt` у всех `<img>`, `aria-label` у кнопок-иконок, семантический HTML5.
7. **Performance** — `loading="lazy"` у изображений ниже первого экрана, `font-display: swap`.
8. **Анимации** — только CSS (`transition`, `@keyframes`) + `IntersectionObserver` для scroll-triggered. Без библиотек анимации.

## Типографика (дефолт, если бренд не диктует другое)

Заголовки — акцентный geometric/display шрифт (напр. Unbounded 600/700). Тело текста — нейтральный sans (напр. Inter 300/400/500). Подключение через Google Fonts CDN в `<head>`.

## Критерии качества перед сдачей

- [ ] Страница даёт "вау-эффект" с первого экрана
- [ ] Градиенты мягкие, не кричащие
- [ ] Все элементы скруглены (border-radius ≥ 16px)
- [ ] Карточки — с hover-эффектом (подъём + тень)
- [ ] Анимации при скролле плавные, не дёрганые
- [ ] Шрифты подгружаются без мерцания (font-display: swap)
- [ ] Пройден anti-pattern чек-лист "отказ от ИИ-шности" — см. `design-library/landing-patterns.md` секция 6 (без pill-бэйджей, градиентного текста, глянцевых кнопок)
